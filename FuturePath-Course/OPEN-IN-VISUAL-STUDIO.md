# Open the application

1. Extract the entire ZIP into a new folder.
2. Open **FuturePath.sln** with Visual Studio 2026.
3. Press **F5**. If needed, choose **Prepare demonstration database** in the app.

Install **.NET desktop development**, **.NET 10 SDK** and **SQL Server Express LocalDB** through Visual Studio Installer. If Visual Studio asks for a startup project, choose **FuturePath.Desktop**.

**FuturePath.Development.sln** is for automated test development. The application solution does not start a test console. See README.md for the fictional staff accounts and docs/Presentation-Guide.md for the demonstration.
